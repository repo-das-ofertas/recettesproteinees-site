Politique de confidentialité

Dernière mise à jour : 7 novembre 2026

Achat et paiement (Hotmart)

Lorsque vous payez via Hotmart, le traitement des données liées à l’achat et au paiement est réalisé dans le cadre des services Hotmart. Pour le détail de leurs traitements, consultez la politique de confidentialité Hotmart : https://hotmart.com/fr/legal/politique-de-confidentialite

Mini-application

Sur l’appareil que vous utilisez, la mini-application peut enregistrer localement vos favoris et votre liste de courses dans le stockage du navigateur. Ces éléments restent sur votre appareil ; les effacer depuis les paramètres du navigateur les supprime. Cette description correspond au fonctionnement technique documenté de la mini-application ; elle ne décrit pas un compte d’accès acheteur opérationnel.

Pages de vente

Les pages de vente peuvent charger des outils de mesure publicitaire (par exemple un pixel Meta et un événement de type PageView) uniquement si un identifiant est configuré. Dans la configuration actuelle, l’identifiant du pixel Meta est renseigné : la page de vente charge ce pixel pour l’événement PageView uniquement et charge aussi le script LabOfertas.

Droits relatifs à vos données

Selon le droit applicable, vous pouvez disposer notamment des droits d’accès, de rectification, d’effacement, d’opposition, de limitation du traitement et de portabilité. Vous pouvez également introduire une réclamation auprès de la CNIL (https://www.cnil.fr/). Pour les données traitées par Hotmart dans le cadre de l’achat, utilisez les canaux indiqués dans la politique de confidentialité Hotmart. Pour toute autre demande relative à votre achat, utilisez les coordonnées d’assistance indiquées dans votre e-mail de confirmation d’achat.
